## 部署

### 获取项目

- 克隆仓库
    ```shell
    git clone --recurse-submodules https://github.com/Spr-Aachen/LLM-PromptMaster
    ```

- 更改工作目录
    ```shell
    %cd LLM-PromptMaster
    ```

### 安装依赖

- 安装项目依赖
    ```shell
    pip install -r requirements.txt
    ```

### 启动程序

- 从客户端启动
    ```shell
    run.py
    ```
