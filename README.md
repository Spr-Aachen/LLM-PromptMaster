## Deployment

### Obtain Project

- Clone Repository
    ```shell
    git clone --recurse-submodules https://github.com/Spr-Aachen/LLM-PromptMaster
    ```

- Change directory
    ```shell
    %cd LLM-PromptMaster
    ```

### Install Dependencies

- Install project requirements
    ```shell
    pip install -r requirements.txt
    ```

### Run Programm

- Start the client
    ```shell
    run.py
    ```
